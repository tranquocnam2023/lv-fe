3. LUỒNG XỬ LÝ DỮ LIỆU & KẾT NỐI API (DATA FLOW)
--------------------------------------------------------------------------------
- Payload gửi lên Backend (/Chatbot/chat):
  {
    "message": "Nội dung câu hỏi người dùng nhập",
    "history": [
      { "role": "user", "content": "..." },
      { "role": "assistant", "content": "..." }
    ] // Duy trì ngữ cảnh tối đa 12 tin nhắn gần nhất (.slice(-12))
  }
- Phản hồi từ Backend:
  {
    "reply": "Nội dung phản hồi được tạo từ AI"
  }
- Xử lý lỗi (Error Handling):
  - Hiển thị hộp thông báo lỗi màu vàng cam nếu kết nối API thất bại.
  - Phản hồi mặc định nhẹ nhàng: "Mình chưa xử lý được yêu cầu này. Bạn thử lại sau nhé."
